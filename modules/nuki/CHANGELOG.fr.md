# Changelog

## 1.0.0 (2026-09-29)

Première version stable. Le pont entre une serrure Nuki et le livret : le module Accès reçoit le code clavier et, si un compte est connecté, l'ouverture à distance.

* Une serrure Nuki transmet son code clavier voyageur au module Accès, qui l'affiche au moment prévu.
* Avec le compte Nuki de l'hôte connecté, le livret gagne aussi l'ouverture à distance.
* L'hôte renseigne l'identifiant de la serrure, son nom et le code clavier, puis la choisit dans Accès.
* Le module n'ajoute rien au livret par lui-même.
