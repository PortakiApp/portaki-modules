## 1.0.0 (2026-09-29)

First stable release. The bridge between a Nuki smart lock and the booklet: the Access module gets the keypad code and, when connected, remote unlocking.

* A Nuki smart lock hands its guest keypad code to the Access module, which shows it at the scheduled time.
* With the host's own Nuki account connected, the booklet also gets remote unlocking.
* The host enters the lock ID, its name and the keypad code, then picks it as the smart lock in Access.
* The module adds nothing to the guest booklet of its own.
