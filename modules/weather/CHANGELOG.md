# Changelog

## 1.0.0 (2026-09-29)

First stable release. The weather where the guest actually is, in the booklet and in the arrival email.

* Guests see current temperature and conditions, the UV index when available, and a 5-day forecast for the address.
* A weather summary also appears in the arrival-day email.
* The host only picks temperature units and refresh frequency; forecasts follow the property's address.
* Weather data comes from Portaki; there is nothing for the host to connect.
