## 1.0.0 (2026-09-29)

First stable release. Every appliance in the rental gets its own how-to card, so guests stop guessing at the oven dial.

* Each appliance gets its own card: the room it is in, how to use it and a link to its manual.
* A safety notice, written once for the property, is shown with the list.
* The host adds, edits, features or hides appliances from an Appliances tab.
