# Changelog

## 1.0.0 (2026-09-29)

First stable release. What is on near the rental this week, found automatically, without the host maintaining an agenda.

* Guests see upcoming concerts, outings and local happenings near the rental, with a map when the venue is known.
* Events are found automatically within a radius the host sets, from 10 to 100 km.
* The host can add up to six events by hand, and a notice shown under the list.
* Local events listings come from Portaki; there is nothing for the host to connect.
