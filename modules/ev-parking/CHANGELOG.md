# Changelog

## 1.0.0 (2026-09-29)

First stable release. Guests arriving in an electric car get their spot, the gate code and the charger PIN without a phone call.

* Guests driving electric find their reserved spot, the gate code and the charger PIN, with a map link and the host's instructions.
* Codes appear on the host's schedule: from booking, 24 h before, the day before at 4 pm, or at check-in.
* The spot is also named in arrival emails, so it is read before the car is parked.
* The host sets spot, codes, directions and instructions from an EV parking tab.
