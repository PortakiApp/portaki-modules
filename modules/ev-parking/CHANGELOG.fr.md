# Changelog

## 1.4.0

Montée technique.

* Le module est passé à la dernière base technique de Portaki ; rien ne change pour l'hôte ni pour le voyageur.

## 1.3.0

La recharge et le stationnement dans la langue du voyageur.

* Tous les textes que lit le voyageur existent dans les dix langues du sélecteur du livret.

## 1.0.0 (2026-09-29)

Première version stable. Le voyageur qui arrive en voiture électrique a sa place, le code barrière et le code de la borne, sans un coup de fil.

* Le voyageur en voiture électrique trouve sa place réservée, le code barrière et le code de la borne, avec un lien carte et les consignes.
* Les codes apparaissent selon le calendrier de l'hôte : dès la réservation, 24 h avant, la veille à 16 h ou à l'arrivée.
* La place est aussi rappelée dans les e-mails d'arrivée, donc lue avant de se garer.
* L'hôte renseigne place, codes, itinéraire et consignes depuis un onglet Parking VE.
