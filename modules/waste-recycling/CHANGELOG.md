# Changelog

## 1.0.0 (2026-09-29)

First stable release. Which bin takes what, and which morning it goes out — the two questions every guest gets wrong.

* Guests see each bin with its colour and what goes in it.
* Collection days are listed, so the bins go out on the right morning.
* The host describes up to six bins and the local collection days from a Recycling tab.
