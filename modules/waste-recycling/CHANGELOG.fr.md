# Changelog

## 1.4.0

Les points de collecte, le compost, et un seul bloc dans l'e-mail.

* Les points de collecte et le compost complètent le tri, avec leur emplacement.
* Le tri tient en un seul bloc dans l'e-mail du lendemain du départ.
* Tous les textes que lit le voyageur existent dans les dix langues du sélecteur du livret.

## 1.0.0 (2026-09-29)

Première version stable. Quel bac prend quoi, et quel matin le sortir — les deux questions que tous les voyageurs ratent.

* Le voyageur voit chaque bac avec sa couleur et ce qu'on y jette.
* Les jours de collecte sont indiqués, pour sortir les bacs le bon matin.
* L'hôte décrit jusqu'à six bacs et les jours de collecte depuis un onglet Tri.
