# Changelog

## 1.0.0 (2026-09-29)

Première version stable. Le nom du réseau et le mot de passe, affichés au bon moment, plutôt qu'une photo de l'étiquette de la box.

* Le voyageur trouve le nom du réseau et le mot de passe dans le livret, avec une astuce et les étapes pour se connecter.
* Le mot de passe apparaît selon le calendrier de l'hôte : dès la réservation, 24 h avant, la veille à 16 h ou à l'arrivée.
* L'hôte remplit une fiche Wi-Fi — nom du réseau, mot de passe, astuce et étapes de connexion.
