# Changelog

## 1.0.0 (2026-09-29)

First stable release. House rules as a few readable points rather than a wall of text nobody finishes.

* House rules read as short points with an icon — quiet hours, pets, noise, number of guests.
* Guests see a preview first, then the full list.
* The host adds, edits and removes rules from a House rules tab, each an icon, a title and a subtitle.
