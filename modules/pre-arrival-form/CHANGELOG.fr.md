# Changelog

## 1.3.0

Montée technique.

* Le module est passé à la dernière base technique de Portaki ; rien ne change pour l'hôte ni pour le voyageur.

## 1.2.0

Le formulaire d'avant-arrivée dans la langue du voyageur.

* Tous les textes que lit le voyageur existent dans les dix langues du sélecteur du livret.

## 1.0.0 (2026-09-29)

Première version stable. Les quelques choses à savoir avant l'arrivée d'un voyageur, demandées une fois, dans le livret.

* Avant l'arrivée, le voyageur remplit un court formulaire : heure d'arrivée, occasion, allergies, nombre de voyageurs, besoins, pièce d'identité.
* Un e-mail prévient le voyageur quand le formulaire est disponible, et les réponses arrivent dans le détail du séjour.
* L'hôte choisit les questions et le moment d'affichage : dès la réservation, 48 h avant, ou le jour de l'arrivée.
