# Changelog

## 1.3.0

Les contacts saisis, et le numéro de l'hôte déjà connu.

* L'onglet de l'hôte n'affiche plus six emplacements vides : il dessine ce qui est saisi, et un bouton ajoute la ligne suivante.
* Le numéro de l'hôte vient de son compte Portaki quand il ne l'a pas saisi dans le module.

## 1.2.0

Les numéros d'urgence dans la langue du voyageur.

* Tous les textes que lit le voyageur existent dans les dix langues du sélecteur du livret.

## 1.0.0 (2026-09-29)

Première version stable. Les numéros dont le voyageur a besoin dans un mauvais moment, dans le livret plutôt que dans un fil de SMS.

* Le voyageur trouve les numéros utiles choisis par l'hôte — pharmacie, médecin, dépannage — et le rappel du 112.
* L'hôte peut afficher son téléphone direct, pour que le voyageur sache toujours qui appeler.
* Un onglet Urgences réunit votre numéro et jusqu'à six contacts, chacun un intitulé et un numéro.
